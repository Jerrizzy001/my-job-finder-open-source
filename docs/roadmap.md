# Roadmap

Open-source, local, single-user. In rough order:

- **Co-op terms:** more term formats ("8 or 12 months", "January start"), and terms stated only in the description's dates table.
- **JSON-LD pages:** paginated career listings and more link layouts, with fixtures.
- **Extension:** Ashby forms embedded on employers' own domains; Ashby's searchable location field.
- **Tailor:** a Markdown→PDF theme option, and section selection for long resumes.
- **Matching:** families for more non-technical work, so non-tech searches get the same family tier.
- **Packaging:** a published npm package with `npx jobfinder`.

Not planned here, by design: autonomous applying, other ATS apply lanes, board harvesting at scale, multi-user hosting. Those are what [My Job Finder](https://myjobfinder.live) does.
