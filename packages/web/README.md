# @jobfinder/web

The local UI. `npm run build:web` from the repo root builds it into `dist/`, which `jobfinder serve` serves. For development, run `jobfinder serve` and then `npm run dev -w @jobfinder/web` (Vite on 5173, API proxied to 4321).

Keyboard: `j`/`k` move through jobs, `d` drafts, `o` opens the posting, `x` is "not for me".
